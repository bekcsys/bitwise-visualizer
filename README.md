# PLC Bit Visualizer

An interactive tool for visualizing PLC memory,
binary data, hexadecimal values, and data types.

![Image Description](/doc/16b-viz.png)

## Features
- 8-bit, 16-bit, 32-bit, and 64-bit visualization
- Signed and unsigned integer representation
- Binary, decimal, and hexadecimal conversion
- PLC memory and register visualization


| Raw HEX | INT16 | UINT16 |
|---|---:|---:|
| 0x0000 | 0 | 0 |
| 0x0001 | 1 | 1 |
| 0x7FFF | 32767 | 32767 |
| 0x8000 | -32768 | 32768 |
| 0xFFFF | -1 | 65535 |
| 0xFF9C | -100 | 65436 |
